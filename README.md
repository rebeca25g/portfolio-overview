## 🔍 Project Summaries

### 1. Accounts Payable Invoice Analysis
Analyzed 5,000 simulated AP invoices to identify inefficiencies in the invoice lifecycle. Uncovered that 19.7% of invoices were blocked, with duplicate invoices and wrong coding as the leading root causes. Built an interactive Power BI dashboard covering payment performance, vendor analysis, and approval bottlenecks.

**Key finding:** The Finance department's approval time (~7.5 days) was 67% longer than Procurement, making it the primary processing bottleneck.
